# Bilingual Resume Generator

Three recovered Python scripts generate targeted English PDFs and Chinese Word/PDF resume layouts for business/data analytics, consulting/strategy, and investment research.

The source retains the original layout and content logic. Phone/email fields have been replaced with placeholders. Python requirements are listed at repository root. The English PDF script expects Windows Calibri fonts; Chinese Word generation uses `python-docx`. Inspect the scripts' output and font settings before running on another operating system. Rendering and PDF conversion may require additional local software.

`build_cn_full.py` imports shared helpers from `build_cn_resumes.py`; keep all three files together. Public source does not include transcripts, reference reports, or private contact details.

Course-specific loan-model result figures are generalized in this public template. Original content remains local.
