# MATLAB signal processing and SVD compression

Two Math 325 (Spring 2026) mini-project scripts, found as original files on Adrian's laptop. Course starter code and AI assistance are included; they are supporting exercises, not separate portfolio projects.

| File | What it does |
| --- | --- |
| `dft_audio_filters.m` | Takes the DFT of a 440 Hz tone and of an audio clip, then builds a 500 Hz low-pass and a 1000 Hz high-pass filter in the frequency domain and writes the filtered audio |
| `svd_image_compression.m` | Compresses a grayscale image with rank-k SVD (k = 50, 100, 150) and compares storage cost and JPG file size with the original |

The input files (`brass.mp3` and the course image) are course materials and are not included. Put your own audio clip or image next to the script and change the file name. MATLAB was not run here.
