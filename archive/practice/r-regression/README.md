# R Regression Learning Examples

Recovered R code from AD571 classroom discussions, using the `Ecdat::Housing` dataset for simple and multiple linear regression, prediction, and visualization. Install `Ecdat` and `ggplot2` separately, then run the selected script.

The examples are educational code recovered from AI-assisted conversations. They are distinct from the NHPA housing project and NYC transaction analysis, and no numerical output is claimed without a current R run.
