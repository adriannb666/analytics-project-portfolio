# Data and attribution

This repository publishes source code and original project summaries. It does not include organizer CSVs, employee-review text, hiring records, trading-account records, wallet addresses, API credentials, academic transcripts, private correspondence, or complete chat histories.

The employer-analysis notebooks originally used competition datasets. Obtain permission and provide those files locally before rerunning. Embedded compressed copies have also been removed: clearing displayed notebook outputs alone would not have removed them.

Team projects are credited to their teams. AI assisted coding, dictionary design, evidence organization, translation, and documentation where used. A code archive does not establish sole authorship, completion of human validation, or successful deployment.

No blanket license is granted over team work, datasets, or third-party software. Dependency licenses remain with their owners. Historical investment simulations and technical indicators are research examples; no live-performance claim is made.

Frozen review/job identifiers and employer-specific case-row claims embedded in source were removed from public copies after publication review. Only generic methods and empty evidence-table schemas remain.
