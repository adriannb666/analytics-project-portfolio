# Gold and Bitcoin Trading Strategy

Three-person project using EMA rules, VaR/CVaR portfolio constraints, and transaction costs in a 2016-2021 simulation. Historical return figures are not current or independently reproduced here.

**Archive status:** Historical MATLAB indicator/backtest fragments and LaTeX report fragments recovered. The final end-to-end strategy implementation remains unrecovered.

See [SOURCE_INDEX.md](SOURCE_INDEX.md) for recovered files. Numbering reflects extraction, not a verified release sequence. Team work and AI-assisted source are preserved as historical material.

## Reuse and limits

The MATLAB fragments cover data loading, moving averages, crossover signals, RSI/StochRSI, and small portfolio simulations. They do not reproduce the complete final EMA plus VaR/CVaR experiment described in the project summary. Historical report prose is a draft, not independently verified evidence of performance.
