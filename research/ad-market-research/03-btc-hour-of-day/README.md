# 03 · 比特币一天里哪个小时最赚钱？

2026-11-09 · BTCUSDT 1 小时 · 2020-01-01 ~ 2026-11-08 · 60,064 根 K 线

## 主要发现

| 发现 | 数字 |
| --- | --- |
| 最强的一小时 | 美东 17:00–18:00（北京时间冬令时 06:00 / 夏令时 05:00）：平均 +6.25 基点，上涨概率 55.1%，t = 4.97 |
| 其余 23 小时 | 平均 +0.13 基点 |
| 占全部涨幅 | 这一小时贡献约 2/3 的对数收益（15,650 / 23,405 基点） |
| 只拿这一小时 / 拿其余 23 小时 / 一直拿着 | 4.8 倍 / 2.2 倍 / 10.4 倍（不计手续费） |
| 分年 | 7 年里 6 年为正，4 年排全天第一（2023 年例外） |
| ETF 前后 | 上市前 +7.1 基点，上市后 +5.0 基点，两段都排第一 |
| 换时钟 | 按北京时间最高 t = 2.91；按美东时间 t = 4.97 → 跟着美国作息走 |
| 星期 | 美东周六这一小时 −1.1 基点，其他六天都是 +5 到 +10 |
| 波动最大 | 美东 10:00–11:00（美股开盘后），平均 55.7 基点，成交额占 6.8% |
| 周末 | 波动比工作日低约 3 成，成交额占比 9–11%（工作日 15–16%） |
| 手续费 | 每天进出一次：合约挂单（来回 0.04%）剩 1.8 倍，现货（来回 0.2%）剩 0.03 倍 |

## 文件

- `hour_of_day.mjs`：下载数据并计算全部统计，输出 `results.json`
- `hdata.py`：画图用的统计结果
- `plot_hr.py`：生成 `figures/` 里的 9 张图

```bash
node hour_of_day.mjs
python3 plot_hr.py
```

## 局限

只统计了币安 BTCUSDT；属于历史统计，效应已经在变弱；「为什么是这个时间」只是推测。CME 从 2026-05-29 起把加密期货改为 7×24 交易，之后这一小时平均 +3.1 基点，但只有 163 个样本，暂时看不出变化。
